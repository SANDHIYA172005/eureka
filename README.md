# Eureka Academy & S3 Dance Studio — Website

Static website for Eureka Academy (a unit of Edu Well), Moolapalayam, Erode.

- `index.html` — home page (Eureka Express train hero + page hooks)
- `about.html`, `courses.html`, `toddler-care.html`, `events.html`, `blog.html`, `contact.html`, `faq.html`
- `courses/` — 9 course pages
- `rooms/` — 4 room pages
- `blog/` — 4 articles
- `assets/` — CSS, JS, logo, photos, posters, team photos
- `hero-options*.html`, `hero-kids.html` — hero design previews (not linked from the site)
- `sitegen/` — Python scripts used to generate/edit the pages

Open `index.html` in a browser, or serve the folder with any static host.
